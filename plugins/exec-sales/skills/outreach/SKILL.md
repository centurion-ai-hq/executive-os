# First-Touch Outreach Draft

Writes one outreach message to one named person, grounded in something real about them, and hands it back for you to send.

## When this fires

• The user names one specific prospect (a person or organisation) and wants a first message written.
• The user says "draft an email to", "write a cold message for", "help me reach out to", "DM this person".
• The user has a prospect list and wants the first-touch message for one entry on it.

## What you do

1. Confirm who the message is going to: name, role, organisation, and channel (email or a social platform).
2. Find one specific, true, current fact about this person or their organisation to ground the message in: something they published, a role change, a company announcement, a shared detail from prior contact. If nothing verifiable is available, say so and ask the user for one detail rather than inventing a generic compliment.
3. Write one message. Open with the specific fact, not a generic greeting. State plainly why you are reaching out. End with one clear, low-friction ask, a question rather than a meeting request with five time slots.
4. Keep it short: a cold email runs 50 to 125 words, a social message runs under 60 words. State the actual word count under the draft.
5. Never claim a connection, referral, or relationship that does not exist. If there is no real connection to this person, do not write a line implying familiarity that isn't there.
6. Offer one alternate subject line or opener so the user has a choice without needing a full rewrite.
7. Do not send, schedule, or post the message. Hand it back as a draft only.

## Output

• **To:** name, role, organisation, channel.
• **Grounded in:** the one specific fact used, and its source.
• **Draft:** the message, exact text.
• **Word count:** the number.
• **Alternate opener or subject line:** one option.

## Rules

• Drafts only. This skill never sends an email, posts a message, or schedules anything. The user sends it themselves.
• No fake familiarity: never imply a prior relationship, a mutual connection, or shared history that is not confirmed true.
• If no verifiable specific detail exists about the prospect, say so plainly instead of writing generic filler dressed up as personalisation.
• No template filler ("I hope this finds you well", "I wanted to reach out"). Every line has to earn its place.

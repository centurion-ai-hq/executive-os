# Unit Economics

Works out what one unit, one customer, one job, or one product, actually costs and actually earns,
with the math shown in the open so the executive can check every step.

## When this fires
• The user asks "what does it cost us per customer," "what's our margin per job," or "is this
  pricing actually profitable."
• The user wants a break-even number before setting a price or taking on a new line of work.
• Before scaling anything: more of a losing unit is a bigger loss, not a bigger business.

## What you do
1. Name the unit clearly first: one customer, one job, one product, one shift, whatever the
   executive means by "one" here. Confirm it before doing any math.
2. Ask for inputs one at a time, not as a wall: the revenue per unit, the direct cost per unit
   (materials, direct labor, direct fees), and any cost that only exists because this unit exists.
3. Separate direct costs from overhead. Overhead (rent, admin, tools that run regardless of volume)
   does not belong in the per-unit number unless the executive wants a fully-loaded view, in which
   case allocate it explicitly and say how.
4. Show the arithmetic step by step: revenue minus direct cost equals contribution per unit.
   Contribution per unit divided into fixed costs equals the break-even unit count. Do not skip to
   the answer.
5. State the margin as both a dollar figure and a percent.
6. Flag every input that was guessed rather than measured. A guessed input makes the whole answer a
   guess, and the output says so plainly rather than presenting a clean-looking number.
7. If the unit loses money, say so directly and name the smallest change (price, cost, or volume)
   that would flip it to profitable.

## Output
The inputs as given, the arithmetic shown line by line, the contribution margin ($ and %), the
break-even count, and a flag list of any guessed input. One page.

## Rules
• This skill analyses the executive's own unit, never gives personalised investment advice, and
  never executes a price change or a transaction. Asked for investment advice, it says plainly it is
  not a licensed advisor and stops.
• Show the math. Never hand back a bottom-line number without the steps that produced it.
• A guessed input gets flagged every time, even if the executive does not ask.
• Ask before this analysis is used to change a price with a customer, a vendor rate, or anything
  that leaves this room. It only calculates, it does not commit.
• No em dashes. Bullets use •.

Send Pack

What to do yourself first, then exactly what to send her, and how.

The short version

Send her one email with the link. Then do the first thirty minutes with her live, on a call or in person, because the setup is a conversation and the first question is what she wants to name it. Do not send it and hope.

Part 1: run it yourself first, today

Twenty minutes. Do not send her anything until you have watched this work once.

  1. Open Claude Code in a folder you do not mind cluttering. A new folder is cleanest.
  2. Install it. Type these two lines, one at a time: /plugin marketplace add centurion-ai-hq/executive-os /plugin install exec@centurion Then install one lane pack. For testing, sales is fine: /plugin install exec-sales@centurion
  3. Check it landed. Say, in plain words: how many skills do I have now You should hear 32. If you hear a much bigger number, you are seeing your own personal library too, which is fine and expected on your machine.
  4. Prove the automatic firing. Say something you would never phrase as a command: ok a few things, I need to call Dave back, the renewal is due, and did we ever pay that invoice It should split that into a numbered list and sort it, without you naming a skill. That is the whole product working.
  5. Run the morning brief once, by hand. Say: run my morning brief It writes a one-page HTML file to briefs/ and tells you the path. Open it. If your calendar and email are not connected it will say so plainly rather than inventing a meeting, which is the behaviour you want to see.
  6. Schedule it. Say: run my morning brief every weekday at 7am Then ask "when does it next run?" and check the answer is a real time.
  7. Turn it off again when you are done testing: stop the morning brief
Three things about the schedule that surprise people
  • It runs in local time. 7am means 7am where she is.
  • It only runs while the app is open. If her laptop was shut at 7am, the brief appears when she opens it. For a morning read that is usually what you want, but say it out loud so it is never a surprise.
  • Each run starts with no memory of any conversation, so the scheduled instruction is written out in full. That is why it produces the same shape every day.

Part 2: the email to send her

Copy the block below. Change the name and the time. Send nothing else with it.

Subject: Your setup, and 30 minutes on Thursday

Hi [NAME],

I have put together the thing I mentioned. It is an assistant that sits on your laptop, remembers how you like to work, and does real work rather than just answering questions. You do not need to learn anything technical to use it. You talk to it the way you would talk to a chief of staff.

Two things from you:

1. Before we talk, open this page and read the first section only. It is three pages and you do not need the rest yet:
https://github.com/centurion-ai-hq/executive-os

2. Book me 30 minutes and we will set it up together on a call. It asks you about a dozen questions as it installs, and the first one is what you want to name it. I would rather be there for that than have you do it alone.

You will need a Claude account beforehand. If you do not have one, make one at claude.ai and tell me which plan you picked so I can check it is enough.

One thing worth knowing now: it will never send an email, post anything, or spend money without asking you first. It writes the draft, you press send. That does not change.

[YOUR NAME]

Part 3: what she literally types

After Claude Code is installed on her machine. Two lines, that is all.

/plugin marketplace add centurion-ai-hq/executive-os /plugin install exec@centurion

Then one lane pack, whichever matches her work:

Her workShe types
Carries a number/plugin install exec-sales@centurion
Runs the machine/plugin install exec-ops@centurion
Watches the cash/plugin install exec-finance@centurion
Board or a mission/plugin install exec-mission@centurion

After that she says "start my setup" and it interviews her. Twelve questions, one at a time, applied as she answers. She never types another command.

How to send it: the honest comparison

OptionVerdict
Email + a live callDo this. The link is durable and she can find it again. The call covers the setup interview, which is a conversation, not a download.
Email aloneShe will open it, hit the first unfamiliar word, and put it in the "later" pile. You will find out in three weeks.
Text with the linkFine as a nudge after the email. Not as the delivery.
Do the whole thing for herTempting and wrong. She will not use what she did not watch get built, and the name question only works if she answers it.
